# FindString

**Мови:** [English](README.md) | Українська | [Deutsch](README.de.md)

FindString — безкоштовна програма для Windows (DDN Research, Україна) для програмістів. Вона знаходить у вибраній папці (включно з усіма вкладеними) всі файли, що містять задане слово, фразу або назву функції, і дозволяє відкрити знайдені файли у вбудованому переглядачі або у вашому редакторі.

## Завантаження

Завантажте `FindString.exe` зі сторінки [Releases](../../releases). Встановлення не потрібне — програма складається з одного EXE.

## Системні вимоги

| | |
|---|---|
| ОС | Windows 7 / 8 / 8.1 / 10 / 11 (32 або 64 біт) |
| Середовище | .NET Framework 4.0 або новіше (4.8 вже є у Windows 10 і 11) |
| Диск | < 1 МБ |

Для Windows 7 без .NET 4.x встановіть [.NET Framework 4.8 Runtime](https://dotnet.microsoft.com/download/dotnet-framework/net48).

## Встановлення

1. Скопіюйте EXE у будь-яку папку, наприклад `C:\Tools\FindString`.
2. Запустіть `FindString.exe`.
3. Якщо Windows SmartScreen покаже «Windows захистила ваш ПК», натисніть **Докладніше → Виконати в будь-якому разі** (EXE не має цифрового підпису).

## Швидкий старт

1. Натисніть **іконку папки** і виберіть папку для пошуку. Програма одразу збере всі файли з вибраними розширеннями з цієї папки та всіх підпапок (лівий список).
2. Введіть шуканий текст у поле **Word** (попередні запити можна вибрати зі списку).
3. Натисніть **Find string** або **Enter**. Файли, що містять текст, з'являться у правому списку.
4. **Подвійний клік** на файлі в правому списку відкриває його в переглядачі (або у вашому редакторі). Подвійний клік у лівому списку відкриває файл програмою Windows за замовчуванням.
5. **Esc** зупиняє довгий пошук.

## Головне вікно

| Елемент | Призначення |
|---|---|
| Іконка папки | Вибір папки для пошуку (файли збираються автоматично) |
| Іконка налаштувань | Вікно Settings |
| Іконка інформації | Версія та автор |
| **Search files** | Повторно зібрати список файлів (наприклад, після зміни розширень) |
| Лівий список | Усі файли, в яких буде виконано пошук |
| **Word** | Шуканий текст (історія зберігається протягом сеансу) |
| **Find string** | Почати пошук |
| Правий список | Файли, в яких текст знайдено |
| Рядок стану | Прогрес і кількість файлів |

## Вбудований переглядач

Подвійний клік на знайденому файлі відкриває вікно перегляду:
- **Find** — перехід до наступного входження тексту (після останнього — знову з початку);
- **Prew / Next** — відкрити попередній / наступний файл зі списку результатів.

Переглядач додає зверху тексту один рядок-коментар. Сам файл на диску не змінюється.

## Налаштування (Settings)

- **File(s) extension** — до 25 масок у форматі `*.розширення` (до 8 символів, напр. `*.c`, `*.h`, `*.cpp`, `*.ino`, `*.txt`). Кнопки **Add** / **Delete**.
  Двійкові формати пропускаються автоматично, навіть якщо їх додано: exe, msi, rar, zip, 7z, iso, apk, doc, docx, xls, xlsx, pdf, psd, bmp, jpg, jpeg, mp3, wav, avi, mp4, mpeg, mkv.
- **Run search files with start** — автоматично збирати файли з останньої папки під час запуску.
- **Open file to application** — відкривати знайдені файли зовнішньою програмою (напр. `C:\Program Files\Notepad++\notepad++.exe`) замість вбудованого переглядача.

Налаштування зберігаються у `%APPDATA%\DDN Research\FindString\set.ini`. **Портативний режим:** якщо поруч з EXE є файл `set.ini` (і в папку можна писати), використовується він. Щоб скинути налаштування — видаліть `set.ini`.

## Корисно знати

- Пошук **чутливий до регістру** (`Define` ≠ `define`).
- Кодування визначається автоматично: підтримуються UTF-8/Unicode та ANSI (напр. Windows-1251 з кирилицею). Файли понад 200 МБ пропускаються.
- Великі папки обробляються довше; прогрес видно в рядку стану, Esc — зупинка.
